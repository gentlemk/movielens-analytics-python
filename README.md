# 🎬 MovieLens Analytics: Data Science & EDA Project

Комплексный проект по разведочному анализу данных (EDA) классического датасета **MovieLens Latest Small**. 

Проект демонстрирует навыки проектирования ООП-архитектуры, работы с неструктурированными данными, статистического анализа, обработки текстов (NLP) и написания качественных unit-тестов.

## 🎯 Цели и задачи проекта
Цель работы — исследовать данные о фильмах и пользовательских оценках, выявить скрытые паттерны и понять, как работают рекомендательные системы.
В рамках исследования решались задачи:
*   Анализ структуры контента (жанры, хронометраж, годы выпуска).
*   Анализ коммерческих метрик (бюджеты, кассовые сборы, окупаемость).
*   Выявление **смещений в оценках (Data Biases)** и поиск объективных шедевров с помощью статистических методов.
*   Семантический анализ пользовательских тегов и оценка их пригодности для машинного обучения.

## 🛠 Стек технологий
*   **Язык:** Python 3.10+
*   **Библиотеки:** `collections` (Counter, defaultdict), `datetime`, `re`, `csv`, `requests` (для парсинга внешних данных).
*   **Тестирование:** `pytest` (покрытие 300+ тестами, фикстуры, параметризация).
*   **Инструменты:** Jupyter Notebook, Git.
*   *(Примечание: проект намеренно реализован на чистом Python без использования pandas/numpy для демонстрации алгоритмического мышления и понимания базовых структур данных).*

## 💡 Ключевые результаты исследования (Insights)
В ходе анализа были сделаны следующие Data Science выводы:
1.  **Положительное смещение (Positive Bias):** Пользователи склонны ставить оценки 3.0, 4.0 и 5.0. Низкие оценки используются крайне редко. Средняя оценка 4.0 может означать как «шедевр», так и «проходное кино».
2.  **Проблема малой выборки (Small Sample Size):** Обычное среднее арифметическое искажает топ лучших фильмов. Фильмы с одной случайной оценкой «5.0» обходят признанную классику. Мы решили это с помощью **байесовского сглаживания (Bayesian Smoothing / Weighted Rating)**.
3.  **Закон Парето (Правило 80/20):** Аудитория крайне неоднородна. Всего 20 сверхактивных пользователей (Power Users) сгенерировали более 25% всех оценок в базе.
4.  **Эффект «Длинного хвоста» (Long Tail):** Более 65% пользовательских тегов встречаются всего один раз. Это создает проблему разреженности данных (Curse of Dimensionality), требующую NLP-обработки.
5.  **Поляризация мнений:** Найдены фильмы с максимальной дисперсией оценок, которые раскалывают аудиторию 50/50 (например, «Ведьма из Блэр»). Для рекомендательных систем — это «высокорисковые» объекты.

## 📂 Структура проекта
*   `src/movielens_analysis.py` — основной модуль с ООП-классами (`Movies`, `Links`, `Ratings`, `Tags`).
*   `tests/` — юнит-тесты (`pytest`), покрывающие граничные случаи, валидацию данных и работу с некорректными файлами.
*   `notebooks/movielens_report.ipynb` — интерактивный отчет с визуализацией и выводами.
*   `data/` — исходные CSV-файлы (MovieLens Latest Small).
