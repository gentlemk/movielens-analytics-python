# 🎬 MovieLens Analytics: Data Science & EDA Project

Комплексный проект по разведочному анализу данных (EDA) классического датасета **MovieLens Latest Small**. 

Проект демонстрирует навыки проектирования ООП-архитектуры, работы с неструктурированными данными, статистического анализа, обработки текстов (NLP) и написания качественных unit-тестов.

## 🎯 Цели и задачи проекта
Цель работы — исследовать данные о фильмах и пользовательских оценках, выявить скрытые паттерны и понять, как работают рекомендательные системы.
В рамках исследования решались задачи:
*   Анализ структуры контента (жанры, хронометраж, годы выпуска).
*   Анализ коммерческих метрик (бюджеты, кассовые сборы, окупаемость).
*   Выявление **смещений в оценках** и поиск объективных шедевров с помощью статистических методов.
*   Семантический анализ пользовательских тегов и оценка их пригодности для машинного обучения.

## 🛠 Стек технологий
*   **Язык:** Python 3.10+
*   **Библиотеки:** `collections` (Counter, defaultdict), `datetime`, `re`, `csv`, `requests` (для парсинга внешних данных).
*   **Тестирование:** `pytest` (покрытие 300+ тестами, фикстуры, параметризация).
*   **Инструменты:** Jupyter Notebook, Git.
*   *(Примечание: проект намеренно реализован на чистом Python без использования pandas/numpy для демонстрации алгоритмического мышления и понимания базовых структур данных).*

## 📂 Структура проекта
*   `src/movielens_analysis.py` — основной модуль с ООП-классами (`Movies`, `Links`, `Ratings`, `Tags`).
*   `src/movielens_impl/` — реализация классов (`Movies`, `Links`, `Ratings`, `Tags`).
*   `src/tests/` — юнит-тесты (`pytest`), покрывающие граничные случаи, валидацию данных и работу с некорректными файлами.
*   `src/movielens_report.ipynb` — интерактивный отчет с визуализацией и выводами.
*   `src/data/` — исходные CSV-файлы (MovieLens Latest Small).
